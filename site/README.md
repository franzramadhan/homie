# site

The static homepage for homie.franzramadhan.dev: `index.html` (no build, no
external assets), `logo.svg`, `demo.mp4` and its poster `demo.png` (also the
link preview image). Serve the folder as is from any static host. Colors
follow `../DESIGN.md`.

Published by `.github/workflows/pages.yml` to GitHub Pages on every change
under `site/` on main; `CNAME` sets the custom domain.
